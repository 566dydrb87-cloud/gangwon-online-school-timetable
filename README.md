# 강원온라인학교 시간표 시스템 (상지대관령고등학교)

고교학점제 및 온라인 공동교육과정 수강신청을 바탕으로 시간표를 직관적으로 편성하고, 엑셀 양식 관리 및 파스텔톤 시간표 다운로드를 지원하는 웹 애플리케이션입니다.

---

## 📌 주요 업데이트 및 핵심 기능

### 1. 학생 목록 엑셀 업로드 (NEIS 수강편성 양식 호환)
- **지원 양식**:
  ```
  [개설 과목]                           [편성 학생]
  학년도 | 학기 | 학년 | 편제명 | 개설과목(학점) | 개설강의실 | 계열/학년/학과 | 반 | 번호 | 성명
  ```
- **데이터 추출**:
  - `학년`, `반`, `번호`, `성명`을 자동으로 가져옵니다.
  - `개설과목(학점)` 열이 있는 경우 과목명(예: `인공지능 기초(3)` -> `인공지능 기초`)을 자동 정제하여 기본 과목으로 인식합니다.
  - 배정 상태와 관계없이 모든 학생이 등록되어 교사가 원하는 시간표에 바로 배정할 수 있습니다.
  - **초기 상태**: 기본 더미/예시 학생 데이터가 제거된 깨끗한 빈 상태로 시작합니다.

### 2. 시간표 표기 방식: `과목명(학번이름)`
- **5자리 학번 생성 규칙**:
  - `학년(1자리)` + `반(2자리)` + `번호(2자리)` + `성명`
  - 예시: 1학년 1반 1번 홍길동 &rarr; 학번: `10101`, 이름: `홍길동` &rarr; **`인공지능(10101홍길동)`**
  - 예시: 2학년 3반 5번 강감찬 &rarr; 학번: `20305`, 이름: `강감찬` &rarr; **`빅데이터(20305강감찬)`**
- 시간표 상의 카드와 엑셀 다운로드 파일 모두 동일한 서식으로 깔끔하게 표기됩니다.

### 3. 교시 및 시간 사용자 지정 & 정렬 규칙
- 상단 **[교시 추가]** 버튼을 통해 수업 교시 또는 점심/휴식 시간을 자유롭게 등록할 수 있습니다.
- **정렬 우선순위**:
  1. **1순위**: `교시 번호` (1교시, 2교시, 3교시...)
  2. **2순위**: `시작 시간` (HH:mm)
  - **효과**: 같은 1교시라도 시간이 서로 다른 경우(예: `1교시 09:00~09:50`, `1교시 09:30~10:20`) 교시 번호로 먼저 묶인 뒤 시간 순서대로 가지런히 정렬됩니다.
- 각 교시의 시작/종료 시간은 시간표 테이블 안에서 직접 클릭하여 언제든 임의 수정할 수 있습니다.

### 4. 교사의 개설 과목 관리 및 일괄 배정
- 상단 **[과목 관리]** 메뉴를 통해 학교에서 개설할 과목들을 추가하거나 관리할 수 있습니다.
- 좌측 학생 명단에서 학생들을 체크한 후, **[과목 선택 또는 직접 입력]**, **[요일]**, **[교시]**를 지정하여 **[시간표에 배정]**을 누르면 한 번에 등록됩니다.
- 시간표 상에서 카드를 마우스로 끌어 다른 요일/교시로 이동(Drag & Drop)할 수 있습니다.

### 5. 결과 엑셀 다운로드 (2종)
1. **학급 시간표 엑셀**:
   - `[전체 종합 시간표]` 시트 + 각 `[학년-반별 시간표]` 멀티시트 파스텔톤 서식 파일
   - 각 과목별 고유 파스텔 배경색, 굵은 폰트, 테두리, 중앙 정렬 자동 적용
2. **원천 데이터 엑셀**:
   - 순번, 학년, 반, 번호, 학번(10101), 성명, 학번성명(10101홍길동), 과목명, 시간표 표기명, 배정상태, 배정요일, 배정교시, 수업시간 등이 정리된 데이터 시트
