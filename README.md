# 강원온라인학교 시간표 시스템 (상지대관령고등학교)

고교학점제 및 온라인 공동교육과정 수강신청을 바탕으로 시간표를 직관적으로 편성하고, 백엔드 영구 보존 및 파스텔톤 시간표 엑셀 다운로드를 지원하는 웹 애플리케이션입니다.

---

## 📌 주요 워크플로우 및 최신 기능

### 1. 학생 편성 현황 엑셀 업로드 (학번, 성명 추출)
- **지원 양식**:
  ```text
  [개설 과목]                           [편성 학생]
  학년도 | 학기 | 학년 | 편제명 | 개설과목(학점) | 개설강의실 | 계열/학년/학과 | 반 | 번호 | 성명
  ```
- **데이터 추출**:
  - `학년`, `반`, `번호`, `성명`을 자동으로 가져와 **5자리 학번(예: 10101)**과 성명으로 목록을 구성합니다.
  - 업로드 시점에는 과목이 미배정 상태(`-`)로 등록되며, 교사가 원하는 과목을 지정하여 배정할 수 있습니다.

### 2. 과목 직접 입력 및 목록화
- 좌측 사이드바의 **[1. 과목 선택]** 영역에서 새 과목명을 타이핑하고 `+ 과목 추가`를 누르면 즉시 과목 목록에 등록되고 자동 선택됩니다.
- 등록된 과목은 고유의 파스텔톤 색상이 자동 지정됩니다.

### 3. 순차 배정 흐름 및 다과목 수강 지원
1. 좌측 명단에서 대상 학생들을 체크박스로 선택합니다.
2. 배정할 **[과목]**을 선택하거나 직접 추가합니다.
3. 배정할 **[요일]**과 **[교시/시간]**을 선택합니다.
4. **[선택 학생에게 과목 배정]** 버튼을 클릭하면 학생 목록에 해당 **과목명**이 나타나고 시간표에 카드가 배치됩니다.
- **다과목 수강 지원**: 한 학생이 여러 과목을 수강하는 경우, 학생을 다시 선택하여 다른 과목/시간을 배정하면 새로운 수강 항목으로 자동 추가 등록됩니다.

### 4. 3단 상태 관리 (원클릭 전환)
- **🟢 확정**: 기본 파스텔톤 배경 카드
- **🔺 조정**: 파스텔톤 배경 + 점선 테두리 카드
- **✖️ 폐강**: **회색(Gray) 배경 + 취소선** 카드
- **원클릭 전환**:
  - 학생 목록의 상태 뱃지 또는 시간표 상의 상태 기호(🟢/🔺/✖️)를 클릭할 때마다 **[🟢 확정 &rarr; 🔺 조정 &rarr; ✖️ 폐강 &rarr; 🟢 확정]** 순으로 즉시 변경됩니다.

### 5. 시간표 표기 방식
- **`상태기호 과목명(학번성명)`**
  - 예시 (확정): `🟢 인공지능(10101홍길동)`
  - 예시 (조정): `🔺 빅데이터(10102이순신)`
  - 예시 (폐강): `✖️ 프로그래밍(20305강감찬)` (회색 배경 + 취소선)

### 6. 백엔드 영구 보존 & 클라우드 동기화
- **독립 Node.js Express 백엔드**: `npm start` 실행 시 `data/timetable-db.json` 파일에 실시간 영구 보존
- **Firebase Firestore**: 클라우드 설정 시 다중 컴퓨터/기기 간 실시간 자동 동기화
- **GitHub Pages 실시간 배포**: 어디서든 웹 브라우저로 바로 접속 가능

### 7. 결과 엑셀 다운로드 (2종)
1. **학급 시간표 엑셀**:
   - `[전체 종합 시간표]` 시트 + 각 `[학년-반별 시간표]` 멀티시트 파스텔톤 서식 파일 (폐강 시 회색+취소선 서식 자동 반영)
2. **원천 데이터 엑셀**:
   - 순번, 학년, 반, 번호, 학번(10101), 성명, 학번성명(10101홍길동), 과목명, 상태(확정/조정/폐강), 배정요일, 배정교시, 수업시간 등이 정리된 데이터 시트
